# Lost Signal

This is a game for the "Lost Signal" game jam at Recurse Center. It's
implemented in [Tomo](https://tomo.bruce-hill.com) as a proof-of-concept and
test case for the language.

In the game, you control a spaceship via satellite links. However, if the
spaceship loses line of sight with all satellites, it loses signal and you can
no longer control it (it will maintain the last direction it was given).
Try to reach the end of a series of progressively harder levels!

```bash
make play
```
